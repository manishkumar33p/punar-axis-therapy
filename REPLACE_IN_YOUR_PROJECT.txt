PUNAR AXIS THERAPY - FIREBASE UPDATE

1. Keep your existing public/ folder.
2. Keep node_modules/ out of the ZIP.
3. Replace your existing src/ folder with this src/ folder.
4. Replace package.json with this package.json.
5. Keep your existing package-lock.json initially, then run:

   npm install

   This installs Firebase and refreshes package-lock.json.

6. Copy .env.example to .env.local and add your Firebase Web App config.
7. Publish firestore.rules in Firebase Console.
8. Enable Firebase Authentication -> Email/Password.
9. Create the first management user in Firebase Authentication.
10. Run npm start.

Important:
- Never put a Firebase service-account/private-key JSON into this React project.
- Do not upload .env.local to GitHub.
- If the Firebase project is not configured, the app keeps the old local fallback mode.
